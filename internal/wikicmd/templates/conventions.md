# Wiki Conventions

The shared filing rules for this vault. The `wiki` skill's `SKILL.md` has the
full workflow; this file is the vault-side copy of the load-bearing rules.

- Structure: `projects/` (has a deliverable), `areas/` (ongoing, no end
  state), `resources/` (reference), `archive/` (closed-out folders), and
  `drafts/` (unfiled scratch notes).
- Default note type is **atomic** (one fact/decision/event/recipe per
  file). Use a **topic page** only for explicit long-form writeups.
- Never edit an old atomic note to keep it current — write a new one and
  set `superseded_by:` on the old one instead.
- Frontmatter on every note: `title`, `date`, `type`, `area`, `tags`,
  optional `pinned`, optional `superseded_by`.
- Link notes with `[[wikilink]]` (filename stem, no `.md`).
- Each folder's `_index.md` is generated by `wiki reindex` / `wiki watch`;
  never edit it. The optional hand-written `_overview.md` holds purpose and
  status, with a one-line `summary:` and a `paths:` list of directories.
